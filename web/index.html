古いバージョンも、
ちゃんと育てるサーバー。

DetergentMC は Mojang のバニラサーバーを土台にした、独自の Minecraft サーバーソフトです。
API は DetergentMC 独自のものだけ。プラグインは「バブル」と呼びます。
新しいバージョンだけでなく、過去のバージョンも積極的に開発します。

目指すところ

1

過去のバージョンも積極的に開発する

対応するだけ、維持するだけではありません。古いバージョン向けの開発そのものを DetergentMC の売りにします。

2

新しいAPIのプラグインを古いバージョンでも

過去のバージョンでも新しいバージョンの API に対応させ、新しいバージョン向けのプラグインを古いバージョンでも使えるようにします。

3

古いクライアントでも新しいものが見える

新しいサーバーに古いクライアントで入っても、テクスチャやリソースパックでブロックや UI を追加できるようにします。

4

日本語から始めて、多言語へ

日本語のドキュメント・設定・サポートを土台に、英語をはじめ他の言語にも広げていきます。公開して色んな人に使ってもらうのが目標です。

正直な話

  • 本物のゲームクライアントでの確認は、まだどの組み合わせも行っていません。テストはすべてプロトコルレベルの検証（偽クライアントと本物のバニラサーバー）です。2人同時参加など、実機での確認が必要な項目が残っています。
  • 開発段階です。リソースパックの公開配信場所もまだ決めていません。公開前に改めて決めます。
  • Bedrock には制限があります。インベントリは未対応で、Xbox 署名の検証や暗号化はまだありません。Bedrock 26.60〜26.65（プロトコル 2225）はパケット形式のみ対応で、NetherNet のトランスポートは未対応です。
