Downloads

Pick your Minecraft version, then pick a build number, and download the jar directly. Builds for older versions are listed too.

About the builds

  • Build 2 (latest):One jar that covers every version. Versions 1.16–26.1 all share the same file (DetergentMC-1.16-26.1-2.jar, 6,018,536 bytes, SHA-1: 6929ebe719549746de13215766cc069239a4928f), and 26.3 has its own file (DetergentMC-26.3-2.jar, 6,523,044 bytes, SHA-1: a9dac3d352efdd39b7f8f8f7c22c3be8c28625b0).
  • Build 1:Separate jars for each version (8,183,698 bytes each). Versions 1.18.2 and 26.2 are only in build 1.
  • Release pages:All builds are also available on GitHub Releases.
