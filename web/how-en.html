How it works

DetergentMC runs Mojang's vanilla server as a child process, with a proxy in front of it. The world and ticks are handled by vanilla itself; DetergentMC's layer absorbs the differences between versions.

Three ports

Proxy — 25565

The entry point players connect to. It looks at the client's version and routes it to the matching adapter.

Cross-version adapter (735–777)

Internal vanilla — 25566

Runs Mojang's vanilla server as a child process. World generation, chunks, and ticks are all vanilla's job.

Mojang vanilla server (Java)

Resource pack — 25567

Delivers per-version resource packs. The foundation for showing newer blocks and UI to older clients.

28 per-version packs

Settings go in detergentmc.yml. The public resource pack delivery location hasn't been decided yet, so during development we use loopback delivery (127.0.0.1:25567).

Cross-version adapter

Even when the client and server versions differ, the proxy translates packets and registries to connect them. The point of this design is to let plugins written for newer versions work on older versions too.

  • Packet ID translation: translates the packet numbers that differ by version, using mapping tables.
  • Registry translation: keeps per-version mapping tables for block states, items, sounds, entities, and more. In 1.20.4 alone there are 26,644 block states.
  • Configuration phase synthesis: the 1.19 series has no configuration phase, so the proxy synthesizes the same flow as the 1.20 series.
  • Chat signing: signed chat was introduced in 1.19 (759), and its format changed in 1.19.1 (760). Signature chains across versions are not supported.

Bedrock support

Bedrock Edition clients are accepted through the same proxy. It listens on UDP 19132 and supports 63 RakNet protocols.

  • Chunk translation: converts Java block states to Bedrock runtime IDs. Biomes are converted too.
  • Entity translation: maps 126 Java entity types to Bedrock. Covers spawning, movement, orientation, equipment, effects, riding, and more.
  • Limits: inventories are not yet supported. There is no Xbox signature verification or encryption yet, and no retransmission via NACK. Bedrock 26.60–26.65 (protocol 2225) is packet-format only; the NetherNet transport is not supported yet.

Honest notes

  • No combination has been tested with a real game client yet. Verification is at the protocol level (a fake client and a real vanilla server).
  • Some things can't be converted. Some packets and data are dropped or replaced with neutral values when they can't be converted. See the repository docs for details.
