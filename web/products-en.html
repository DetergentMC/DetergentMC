Products

DetergentMC is a single project. The main software and the plugin system are all developed open and free.

DetergentMC

A Minecraft server software built on Mojang's vanilla server. Written in Java. MIT licensed, with source code published on GitHub.

Vanilla-based

World generation, chunks, and ticks are handled by Mojang's vanilla server itself. DetergentMC adds a proxy layer in front of it.

Its own API only

The API is DetergentMC's own, and only that. There is no compatibility with other server software's APIs. The goal is to support newer APIs even on older versions.

Aiming to support all versions

35 protocols from 1.14.1 to 26.3 are supported, and the final goal is to support everything from 1.0 to the latest. See Versions for details.

Starting in Japanese, expanding to other languages

Built on Japanese documentation, settings, and support, expanding to English and other languages.

Java is required to run it. The required Java version depends on the Minecraft version (1.16 series: Java 8; 1.17 / 1.18 series: Java 16; 1.19 series: Java 17; 1.20.5 and later: Java 21; 26.1, 26.2, and 26.3: Java 25).

Bubbles — what plugins are called

In DetergentMC, plugins are called “Bubbles”, named after detergent bubbles. They are made for DetergentMC's own API.

What is a Bubble?
A plugin that adds features to DetergentMC. Write settings in bubble.yml and place it in the bubbles/ folder.
Can I use plugins from other server software?
No. DetergentMC has only its own API, with no compatibility with other APIs. Making Bubbles made for newer versions usable on older versions, too, is what DetergentMC aims for.
Where can I get Bubbles?
The distribution system has not been decided yet. As this is still in development, finishing the main software comes first.

Honest notes

  • Still in development. Real game clients have not been tested yet; the tests are protocol-level verification.
  • There is no paid version. DetergentMC is a free, open project.
