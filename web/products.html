製品

DetergentMC はひとつのプロジェクトです。本体も、プラグインの仕組みも、すべて公開・無料で進めています。

DetergentMC 本体

Mojang のバニラサーバーを土台にした独自の Minecraft サーバーソフトです。Java で書かれています。ライセンスは MIT で、ソースコードは GitHub で公開しています。

バニラベース

ワールド生成・チャンク・ティックは Mojang のバニラサーバーそのものが担当します。DetergentMC はその前にプロキシの層を載せる構成です。

独自APIのみ

API は DetergentMC 独自のものだけです。他のサーバーソフトの API との互換性はありません。過去のバージョンでも新しいバージョンの API に対応させるのが目標です。

全バージョン対応を目指す

1.16 から 26.3 まで 28 プロトコルに対応済みで、最終的には 1.0 から最新まで対応します。詳しくは対応バージョンをご覧ください。

日本語から始めて多言語へ

日本語のドキュメント・設定・サポートを土台に、英語をはじめ他の言語にも広げていきます。

起動には Java が必要です。必要な Java のバージョンは対応する Minecraft のバージョンによって変わります（1.16 系は Java 8、1.17／1.18 系は Java 16、1.19 系は Java 17、1.20.5 以降は Java 21、26.1・26.2・26.3 は Java 25）。

バブル — プラグインのこと

DetergentMC ではプラグインを「バブル」と呼びます。洗剤の泡にちなんだ名前です。DetergentMC 独自 API 向けに作ります。

バブルとは何ですか？
DetergentMC に機能を追加するプラグインのことです。設定は bubble.yml に書き、bubbles/ フォルダに置きます。
他のサーバーソフトのプラグインは使えますか？
使えません。DetergentMC は独自 API のみで、他の API との互換性はありません。新しいバージョン向けのバブルを古いバージョンでも使えるようにするのが、DetergentMC の目指すところです。
バブルはどこで手に入りますか？
まだ配布の仕組みは決まっていません。開発段階のため、まずは本体の完成を優先しています。

正直な話

  • 開発段階です。本物のゲームクライアントでの確認はまだ行っておらず、テストはプロトコルレベルの検証です。
  • 有料版はありません。DetergentMC は無料・公開前提のプロジェクトです。
