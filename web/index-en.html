DetergentMC is a Minecraft server software built on Mojang's vanilla server.
The API is DetergentMC's own, and only that. Plugins are called “Bubbles”.
Not only new versions, but older versions too, are actively developed.

Downloads

Version-specific jars (DetergentMC-<version>-<build>.jar, 29 jars for 1.18.2–26.2) are published on GitHub Releases. One jar supports all versions (the contents are the same; only the file names differ by version).

  • Available: GitHub Releases (build 1). All 29 jars are build 1. You can also build from source code (GitHub).
  • File name examples: DetergentMC-1.20.4-1.jar, DetergentMC-1.18.2-1.jar, DetergentMC-26.2-1.jar. Build numbers are independent for each version.

Goals

1

Actively develop older versions, too

Not just supporting or maintaining them. Developing for older versions is itself DetergentMC's selling point.

2

New-API plugins on older versions, too

Bring newer APIs to older versions, so plugins made for newer versions can be used on older versions as well.

3

Older clients can see new things, too

Even when joining a new server with an old client, textures and resource packs will make it possible to add blocks and UI.

4

Starting in Japanese, expanding to other languages

Built on Japanese documentation, settings, and support, expanding to English and other languages. The goal is to publish it and have all kinds of people use it.

Honest notes

  • No combination has been tested with a real game client yet. All tests are protocol-level verification (fake clients and real vanilla servers). Items that need real-device testing remain, such as two players joining at the same time.
  • Still in development. We have not decided where to publicly distribute resource packs yet. We will decide before release.
  • Bedrock has limitations. Inventory is not supported yet, and there is no Xbox signature verification or encryption. Bedrock 26.60–26.65 (protocol 2225) is packet-format only; the NetherNet transport is not supported yet.
