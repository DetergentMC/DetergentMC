Roadmap

Starting from 1.20.4, we went up to 1.21.11, back to the 1.19 series, through 26.1 and 26.2, back to the 1.18, 1.17, and 1.16 series, and reached 26.3. We then descended from 578 (1.15.2) down to 1.14.1. The final goal is support for every version from 1.0 to the latest.

The journey so far

2026-11-08

Starting from 1.20.4

We chose our own path built on vanilla and named it DetergentMC. With the proxy, internal vanilla, and resource pack delivery setup, we reached a playable minimum.

2026-11-08 – 09

Cross-connecting the 1.20 series

Mutual connections between client × server, 16 combinations, from 1.20.1 (763) to 1.20.5 / 1.20.6 (766). The reverse direction (a newer client joining an older server) is supported too.

2026-11-10

Bedrock support

Support for 30 RakNet protocols. Translation of chunks, block states, and entities, and started accepting Bedrock clients.

2026-11-10 – 13

1.21 to 1.21.11

Supported versions in order from 1.21 (767) to 1.21.11 (774). Tests reached 2,314.

2026-11-13 – 14

Going back to the 1.19 series

Completed the four 1.19-series protocols, from 1.19.4 (762) to 1.19 (759). 16 protocols, and the matrix reached 256 combinations.

2026-11-15

Supporting 26.1

Completed 26.1 (775). 17 protocols, 289 matrix combinations, and 2,866 tests. The internal server requires Java 25.

2026-11-15

Supporting 26.3

Completed 26.3 (777). The internal server requires Java 25.

2026-11-15 – 16

Going back from the 1.18 series to 1.16

Completed the 8 protocols 757, 756, 755, 754, 753, 751, 736, and 735. By 2026-11-17, all 28 versions had been confirmed to start with fat jars.

2026-11-17

Making every version playable

Startup confirmed for all 28 versions from 735 to 777 with 2 fat jars. Joining with a real game client is still unconfirmed.

2026-11-16 – 17

Descending from 578

Working down one version at a time from 1.15.2 (578), we completed 573, 575, 578 and 498, 490, 485, 480. 1.14 (477) is in final verification. The goal is 335 (1.12).

What's next — not decided yet

What to do next hasn't been decided yet. There are three candidates:

  1. Go further back (1.13.x and earlier) — continue descending from 578 toward the 1.13 series and 335 (1.12). Complete down to 480 (1.14.1); 477 (1.14) is in final verification.
  2. Take Bedrock back to 1.8 — a loop going back one version at a time from the latest; currently supported back to 1.19.70.
  3. Real-client testing — testing with real game clients. No combination has been done yet. Confirming two players joining at the same time is the most important remaining verification.

Once it's decided, this page will be updated too.
