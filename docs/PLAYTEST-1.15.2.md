# DetergentMC 1.15.2 実機プレイテスト — チェックリスト

2026-11-16 作成。1.15.2 クライアント（プロトコル578）で各サーバーに参加する
実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.15.2.md` を参照。

## 0. この手順書の読み方

DetergentMC の 578 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.15.2
クライアントでの見た目・挙動を確かめること。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 578クライアントの 1.15.2 サーバー（内部578）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake578ClientJoinsRealVanilla1152ThroughProxy`）。
  Join Game が 578 形式（次元は数値 0）で届くこと、Spawn Position 0x4e、
  Keep Alive 0x21→0x0f を確認。
- 578クライアントの 1.18.2 サーバー（内部758）への参加・チャット・移動
  （`fake578ClientJoinsRealVanilla1182ThroughProxy`）。578↔758 の一段変換。
- 758クライアントの 1.15.2 サーバー（内部578）への参加・チャット・移動
  （`fake758ClientJoinsRealVanilla1152ThroughProxy`）。Join Game は
  既定 codec（codec-758.bin）で 758 形式に合成される。
- 578↔758 のレジストリ差分（実バニラ 1.15.2 jar のダンプ＋ViaVersion
  mapping-1.15／mapping-1.18 で全件検証）：ブロック状態 11,337⇔20,342、
  アイテム 884⇔1,101、エンティティ 103⇔113、音 810⇔1,203、
  パーティクル 62⇔88、バイオーム 75⇔61。絵画 26 件・エフェクト 32 件は
  両側で同一（表なし）。
- 578 用リソースパック（pack_format 5）の生成と配信。
- Bedrock → 内部578サーバーの配線（単体テストのみ。UDP の制約で
  エンドツーエンドは未実施）。

### B. 実機でしか確認できない項目（この手順書の中心）

- 本物の 1.15.2 クライアントが内部 758／765 サーバーに参加し、
  チャンク（特に光：Update Light の別パケット合成）が正しく描画されるか。
  **最重要**：1.15.2 のチャンク描画は光の扱いが世代違いのため、
  真っ暗／明るすぎる等の異常が出ないか。
- 1.16 以降のブロック（深層岩・銅・ネザライト系など）が 1.15.2
  クライアントで代替表示（石系・鉄系・ダイヤ系）になるか。
- 1.15.2 クライアントで大釜の水位、壁の形、ジグソーの向きが正しいか
  （特殊変換の3件）。
- 雷（Spawn Entity Weather ⇔ lightning_bolt）が正しく表示されるか。
- 2人同時参加（他プレイヤーの出現・スキン・チャット）。
  フェイククライアントでは検証できない（実バニラが Player Info／
  出現パケットを送らないため）。
- 578 用パック（pack_format 5）が提示され適用されるか。
- `/trigger d_hello` 等のデータパックコマンド（直接 `/hello` は動かない）。

## 1. 起動

### 1.1 内部サーバーを 1.15.2 にする場合

- `detergentmc.yml` の `minecraft-version: "1.15.2"`。
- **Java 8 が必要**：`DETERGENTMC_JAVA8_HOME` 環境変数（または
  `detergentmc.java8.home`）に Temurin 8 の場所を指定する。
  未指定だと Java 17 で起動しようとしてバニラが拒否する。

### 1.2 ポート構成

従来と同じ（プロキシ 25565、内部バニラ 25566、パック 25567、
Bedrock UDP 19132）。

## 4. わざと失敗するはずのもの（バグではない）

- 577 以下（1.15.1 以前）のクライアントはログイン時に断られる。
- 579〜757（1.16〜1.17.x）のクライアントはこのツリーでは未対応で
  断られる（別担当の作業場所で対応中）。
- Edit Book（758→578 方向）、Crafting Book Data、Confirm Transaction は
  落とされる。
- Declare Recipes／Statistics／Tags は全方向で未対応。
