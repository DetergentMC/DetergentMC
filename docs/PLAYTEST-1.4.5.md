# DetergentMC 1.4.5／1.4.4 実機プレイテスト — チェックリスト

2026-11-20 作成、49 の Stage A〜D 完了に合わせて作成。
1.4.5 または 1.4.4 クライアント（レガシープロトコル49）で

## 0. この手順書の読み方

DetergentMC の 49 対応は **Stage E まで完了（2026-11-20）**。
単体テスト（分割検証 全 4,830 件・失敗 0）と Stage A の
実測採取（実バニラ 1.4.5 への暗号化ログイン＋歩行＋
チャット 111 パケット完全解析、チャンクバルク実物 34 件・
169 チャンクのサイズ検算まで一致）に加え、実バニラ
統合テスト（ブリッジ fake49→実バニラ 1.7.10、ダイレクト
fake49→実バニラ 1.4.5＝暗号化ログイン込み、49 の §1
ピング完全形、回帰を含む統合セル合計 102 件全合格）でも
確認済み。**残るは本物のゲームクライアントでの確認のみ**。
このチェックリストはその実機確認のためのものである。
1.4.4 は jar 抽出レベルで差分ゼロを確認したのみで、
採取・統合セルは 1.4.5 で代表させている。

49 で特に注意すべき点：

- **落ちたアイテムの見え方（最重点）**：ブリッジモードでは
  アイテムエンティティを 0x17（オブジェクトスポーン種別2）
  で送る。実バニラ 1.4.5 サーバーは専用の 0x15 を使うため、
  **1.4.5 クライアントが 0x17 種別 2 を正しく表示できるかは
  実機未確認**（クライアント側ハンドラはサーバー jar から
  確認できない）。ダイレクトモードでは 0x15 がそのまま
  中継されるので、この心配はない。
- **花火が見えない**：花火ロケット（1.4.6 の追加）は
  49 クライアントにはスポーンされない。花火アイテムは
  紙、花火の星はグローストーンダスト、エンチャントの本は
  本として届く。
- **オブジェクトの回転が無い**：スポーン時の pitch／yaw が
  ワイヤに無い（1.4.6 で追加）。投射物などの初期角度が
  既定向きになることがある。
- 51 と共通の制限も継承する：**スコアボードと名前付き
  パーティクルが無い**、**体力は整数（I16）**、**能力速度は
  バイト量子化**、**馬は豚**、**属性（0x2C）と乗り物操作
  （0x1B）が無い**、1.5 の追加ブロック・アイテムは 51 と
  同じ近似。
- **1.4.5 と 1.4.4 の混在**：どちらのクライアントも同じ
  プロトコル 49 で参加できる。バックエンドも
  `minecraft-version` に `1.4.5` と `1.4.4` のどちらを
  書いてもダイレクトモードで受けられる（ピングには
  設定した名前がそのまま出る）。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 対応レガシー一覧＝[78, 74, 73, 61, 60, 51, 49] の固定と、
  49 表が 51 表から 0x15 追加＋コーデック差し替え 2 件＋
  0x10 方向だけであることの固定
  （`LegacyPacketTableTest`）。
- 49 コーデックでの全パケット往復、pickup_spawn の往復と
  51 での書き込み例外、spawn_object_norot／chunk_bulk_nosky
  のワイヤ長（51 より 2 バイト／1 バイト短い）
  （`LegacyPacketIOTest`）。
- 変換器の 49 処理：花火系アイテムの近似、花火ロケットの
  落とし、ブロック近似の 51 委譲
  （`LegacyPlayTranslatorTest`、`LegacyChunkRemapTest`）。
- フェイク相手での E2E（`LegacyFrontendEndToEndTest`：
  1.4.5 バックエンドへのダイレクト中継（0x15 のネイティブ
  中継を含む）、ブリッジでの 0x85／0x2C 落とし、§1 ピング
  49 / 1.4.5 と 49 / 1.4.4）。
- アダプタ発見（1.4.5 と 1.4.4 の両方）と両名のダイレクト
  配線（`LegacyAdapterTest`、コア側 `LegacyWiringTest`）。

### B. 実機で重点的に見る項目

1. **レガシーピング**：1.4.5／1.4.4 クライアントの
   サーバー一覧に MOTD・人数が表示されること（完全形
   ピングで §1）。
2. **ログイン列（ブリッジ）**：暗号化を含むログインが
   最後まで進み、スポーンできること。51／61 クライアント
   と同時に混在参加できること。1.4.5 クライアントと
   1.4.4 クライアントの同時参加も確認する。
3. **落ちたアイテム（ブリッジ）**：ブロックを壊して
   アイテムが落ちたとき、49 クライアントに表示され、
   拾えること（0x17 種別 2 の受け可否の確認）。
4. **落ちたアイテム（ダイレクト）**：同じことを
   ダイレクトモード（0x15 中継）でも確認する。
5. **ログイン列（ダイレクト）**：`minecraft-version: 1.4.5`
   と `1.4.4` の両方で起動し、内部バニラ（Java 8）へ直接
   つながること。51 クライアントが "Outdated client!" で
   蹴られること。
6. **花火の不在**：現代側で花火を打ち上げても 49
   クライアントで接続が切れず、花火だけが見えないこと。
7. **近似ブロック**：PLAYTEST-1.4.7.md の同項目と同じ
   観点（51 と同じ近似）。
8. **チャンク表示・移動・Keep Alive・エンティティ**：
   PLAYTEST-1.6.4.md の同項目と同じ観点。
