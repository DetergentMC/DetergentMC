# DetergentMC 1.14.2 実機プレイテスト — チェックリスト

2026-11-17 作成。1.14.2 クライアント（プロトコル485）で各サーバーに
参加する実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.14.2.md` を参照。

## 0. この手順書の読み方

DetergentMC の 485 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.14.2
クライアントでの見た目・挙動を確かめること。

485 のワイヤ形式は 490（1.14.3）とほぼ同一（パケットIDは完全一致、
差は Trade List の canRestock の有無だけ）で、変換は 490／498 の
経路を共用している。そのため 490 のプレイテスト項目の大半はそのまま
当てはまるが、村人取引（Trade List の canRestock が無い世代）は
485 固有の分岐を通るので重点的に見てほしい。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 485クライアントの 1.14.2 サーバー（内部485）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake485ClientJoinsRealVanilla1142ThroughProxy`）。
- 485クライアントの 1.14.3 サーバー（内部490）への参加・チャット・移動
  （`fake485ClientJoinsRealVanilla1143ThroughProxy`）。
- 490クライアントの 1.14.2 サーバー（内部485）への参加・チャット・移動
  （`fake490ClientJoinsRealVanilla1142ThroughProxy`）。
- 485 用リソースパック（pack_format 4、`detergentmc-pack-1.14.2.zip`）の
  生成と配信。外部モードの `resource-pack.url-485`／`sha1-485` も配線済み。
- 掘削 ack が 485 クライアントにも 490 クライアントにも届かず
  （両方に存在しない）、498 クライアントには 0x5c で届くことは
  単体テストで確認済み（`ProxySession485Test`）。
- Trade List の demand と canRestock が 758→485 で落ち、485→758 で
  demand=0 と canRestock=isRegularVillager として補われることは
  単体テストで確認済み（`ChunkTranslator485Test`）。

### B. 実機でしか分からない項目

- [ ] 本物の 1.14.2 クライアントで内部 485／490／758 サーバーへ参加し、
      地形・ブロックの見た目が崩れていないか。
- [ ] 村人との取引画面が正しく開き、取引できるか（Trade List の
      canRestock 無し形式の実機確認）。新しいサーバーで 1.14.2
      クライアントに取引画面が出たとき、補充可否の表示が
      おかしくないか（canRestock は isRegularVillager で代用する近似）。
- [ ] ブロックを掘ったときのヒビ・破壊の見た目が正しいか
      （掘削 ack が無い世代のため、違和感が無いか）。
- [ ] チャンクの明るさ（光は別パケット Update Light のため、
      暗転・明るさの段差が無いか）と、バイオームによる草・水の色が
      場所ごとに正しいか。
- [ ] 485 クライアントに 1.14.2 用パック（pack_format 4）が提示され、
      受け入れ後に文字化け・欠落テクスチャが無いか。
- [ ] 2人以上の実クライアントで相互に見えるか（フェイククライアントでは
      実バニラが Player Info／スポーンを送らないため未検証。全バージョン共通の最重要項目）。
- [ ] Bedrock クライアントから内部 485 サーバーへ参加できるか
      （単体テストのみで、実機・統合とも未実施）。

### C. 既知の制限（実機でも再現する想定）

- Declare Recipes／Statistics／Tags／World Event ID は全方向で未実装。
- Trade List の canRestock は近似（isRegularVillager で代用）。
- バイオームの変種（hills 等）は新しいバージョン側では素のバイオームに
  寄るため、草・水の色が実機でも単調になる場合がある。
- その他は 490 と同じ制限（`docs/PROXY-1.14.3.md` の「残る制限」参照）。
