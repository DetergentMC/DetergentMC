# DetergentMC 1.14.4 実機プレイテスト — チェックリスト

2026-11-17 作成。1.14.4 クライアント（プロトコル498）で各サーバーに
参加する実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.14.4.md` を参照。

## 0. この手順書の読み方

DetergentMC の 498 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.14.4
クライアントでの見た目・挙動を確かめること。

498 は 573（1.15）と形式が違う世代のため、578 のプレイテスト結果を
そのまま流用できない。特にチャンク（バイオームの並び、光）と
Join Game まわりは 498 専用変換を通るので、重点的に見てほしい。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 498クライアントの 1.14.4 サーバー（内部498）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake498ClientJoinsRealVanilla1144ThroughProxy`）。
- 498クライアントの 1.15 サーバー（内部573）への参加・チャット・移動
  （`fake498ClientJoinsRealVanilla115ThroughProxy`）。
- 573クライアントの 1.14.4 サーバー（内部498）への参加・チャット・移動
  （`fake573ClientJoinsRealVanilla1144ThroughProxy`）。
- 498 用リソースパック（pack_format 4、`detergentmc-pack-1.14.4.zip`）の
  生成と配信。外部モードの `resource-pack.url-498`／`sha1-498` も配線済み。
- チャンクのバイオーム列が 498⇔758 の往復で（変種の寄せを除き）
  保たれること、World Particles の dust の座標が f32⇔f64 で
  変換されることは単体テストで確認済み。

### B. 実機でしか分からない項目

- [ ] 本物の 1.14.4 クライアントで内部 498／573／758 サーバーへ参加し、
      地形・ブロックの見た目が崩れていないか。
- [ ] チャンクの明るさ（498 は光が別パケット Update Light のため、
      暗転・明るさの段差が無いか）と、バイオームによる草・水の色が
      場所ごとに正しいか。
- [ ] 498 クライアントに 1.14.4 用パック（pack_format 4）が提示され、
      受け入れ後に文字化け・欠落テクスチャが無いか。
- [ ] パーティクル（dust の色・大きさ）が正しく表示されるか
      （座標 f32⇔f64 変換の実機確認）。
- [ ] 2人以上の実クライアントで相互に見えるか（フェイククライアントでは
      実バニラが Player Info／スポーンを送らないため未検証。全バージョン共通の最重要項目）。
- [ ] Bedrock クライアントから内部 498 サーバーへ参加できるか
      （単体テストのみで、実機・統合とも未実施）。

### C. 既知の制限（実機でも再現する想定）

- Declare Recipes／Statistics／Tags／World Event ID は全方向で未実装。
- バイオームの変種（hills 等）は新しいバージョン側では素のバイオームに
  寄るため、草・水の色が実機でも単調になる場合がある。
- その他は 578 と同じ制限（`docs/PROXY-1.15.2.md` の「残る制限」参照）。
