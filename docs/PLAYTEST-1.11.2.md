# DetergentMC 1.11.2 実機プレイテスト — チェックリスト

2026-11-19 作成、Stage A〜D 完了に合わせて作成。1.11.2 クライアント
（プロトコル316）で各サーバーに参加する実機確認のための手順と、
結果の記録用。詳細な仕組みは `docs/PROXY-1.11.2.md` を参照。

## 0. この手順書の読み方

DetergentMC の 316 対応は **Stage A〜E まで完了**。分割検証
（4,020 件・失敗 0）と実バニラ統合テスト（新規 3 セル＋回帰
47 セルの計 50 セルが全合格）で確認済みだが、**本物のゲーム
クライアントでの確認は未実施**。このチェックリストはその
実機確認のためのものである。

316 は 340 世代とワイヤ形式の骨格が同一だが、1.12 の追加要素
（レシピブック・進捗・コンクリート類・知識の書・オウム・
イリュージョナー）が存在せず、**パケットIDが 335 と 61 件ずれる**。
実機では特に、**ID の付け替えが効くパケット全般の見え方**、
**Keep Alive（varint）の往復（切断されずに長時間遊べるか）**、
**1.12 新規ブロック・アイテム・エンティティの近似の見え方**
（コンクリート→羊毛など）が重点になる。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 316 のパケット ID 表（`PacketIds316Test`：316 に存在するのは
  113 件、335 との ID 差分 61 件、335 のみのパケットは
  レシピブック・進捗系の 6 件のみ）。
- 対応クライアント一覧の最古が 316 で、335／338／340 が残り、
  計 34 プロトコル（`ClientAdapter316Test`。最古脱落の罠の固定）。
- レジストリ変換の近似（`RegistryRemapper316Test`：コンクリート→
  羊毛、彩釉テラコッタ→色付き堅焼き粘土、

  エンティティの落下、音名フォールバック。鉄塊は 1.11.1 で

- チャンク往復・crossing 詰め・位置の詰め直し・スロット分割・
  メタデータ型の i8 化と型 13〜16 の落下
  （`ChunkTranslator316Test`、`SlotTranslator316Test`）。
- Join Game／Respawn の 393 形式との往復
  （`PlayTranslator316Test`：difficulty は 758 方向で落ち、

- 316 クライアント×758 サーバーの参加・Login Success の

  316 クライアントの Keep Alive 応答（varint・ID 0x0B）の
  i64 化と切り捨て ID の復元、進捗パケットの落下
  （`ProxySession316Test`）。

  フォールバック順 316 → 335 → 338 → …）
  （`ResourcePackBuilder316Test`、`ResourcePackMode316Test`、
  `ResourcePackServer316Test`）。

### B. 実機で重点的に見てほしい項目

- 1.11.2 クライアントで新しいサーバー（1.20.4 等）に参加し、
  チャット送受信・移動・ブロック破壊／設置が一通りできること。
- 長時間（10 分以上）接続し続けても Keep Alive で切断されない
  こと（varint 付け替え＋復元表の実機確認）。
- 1.12 以降のサーバーでコンクリート・コンクリートパウダーが
  同色の羊毛に、彩釉テラコッタが同色の堅焼き粘土に見えること。
  オウム・イリュージョナーが pig で代用表示されること。
- 新しいクライアント（1.20.4 等）で内部 1.11.2 サーバーに
  参加できること。1.11.2 に無いブロックを置いた場合の見え方。
- インベントリ操作（Window Click、クリエイティブスロット）が
  316 クライアント⇔新しいサーバー間で正しく反映されること
  （itemDamage の付け替え）。
- リソースパックが 316 クライアントに正しく配信・適用される
  こと（316 パックが無い構成では 335 パックで代替されること）。
- 2 人同時参加時の相互表示（プレイヤー一覧・スポーン）。
  fake クライアントでは原理的に確認できない最重要項目。

### C. 既知の制限（実機でも再現する想定のもの）

- 進捗（Advancements）画面・レシピブックは 316 側に存在しない
  ため表示されない（プロトコル自体が無い）。
- アイテム形のコンクリート／コンクリートパウダーは色が落ちる
  （羊毛アイテムになる）。彩釉テラコッタは向きが落ちる。
- **データパックが無い世代のため、`/trigger d_hello` 等の
  trigger ブリッジ（言語切替・hello）は 316 バックエンドでは
  使えない**（335／338／340 から引き継ぐ既知の課題）。
- チャットの署名連鎖はバージョン境界を越えると維持されない
  （全バージョン共通）。
- Bedrock クライアントから 316 バックエンドへの参加は
  単体テストのみで、実 Bedrock クライアント未確認。
