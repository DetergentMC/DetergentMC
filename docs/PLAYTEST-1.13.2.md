# DetergentMC 1.13.2 実機プレイテスト — チェックリスト

2026-11-17 作成。1.13.2 クライアント（プロトコル404）で各サーバーに
参加する実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.13.2.md` を参照。

## 0. この手順書の読み方

DetergentMC の 404 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.13.2
クライアントでの見た目・挙動を確かめること。

404 は 477（1.14）と形式が大きく違う（座標の詰め方、Join Game の
difficulty、チャンク内蔵の光、Spawn Entity のオブジェクト表）ため、
477 以前のプレイテスト項目に加えて、404 固有の変換が実機の見た目に
どう出るかが重点になる。特にチャンク（光・バイオーム）とスポーン
（オブジェクト系／生物系の振り分け）は最優先で確認してほしい。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 404クライアントの 1.13.2 サーバー（内部404）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake404ClientJoinsRealVanilla1132ThroughProxy`）。
- 404クライアントの 1.14 サーバー（内部477）への参加・チャット・移動
  （`fake404ClientJoinsRealVanilla114ThroughProxy`）。
- 477クライアントの 1.13.2 サーバー（内部404）への参加・チャット・移動
  （`fake477ClientJoinsRealVanilla1132ThroughProxy`）。
- 404 用リソースパック（pack_format 4、`detergentmc-pack-1.13.2.zip`）の
  生成と配信。外部モードの `resource-pack.url-404`／`sha1-404` も配線済み。
  404 パックが無い構成では 477 パックで代替することも確認済み。
- チャンクの往復（404→758→404）でブロック・バイオーム・光の配置が
  保たれることは単体テストで確認済み（`ChunkTranslator404Test`）。
- Spawn Entity の振り分け（ボート等のオブジェクト系は i8 の
  オブジェクト ID、生物系は Spawn Entity Living）も単体テストで確認済み。
- Trade List が 404 クライアントに届かないこと、掘削 ack が届かない
  ことは単体テストで確認済み（`ProxySession404Test`）。

### B. 実機でしか分からない項目

- [ ] 本物の 1.13.2 クライアントで内部 404／477／758 サーバーへ参加し、
      地形・ブロックの見た目が崩れていないか。
- [ ] **自然地形のブロック精度**：鉱石・洞窟・木など種類の多い
      セクション（パレットが大きくビット幅が 5 以上になる場所）で
      ブロックが化けていないか（crossing 詰めの確認はここが本番）。
- [ ] **チャンクの明るさ**：404 は光がチャンク内蔵。新しいサーバー
      （758 等）から来たとき、暗転・明るさの段差・真っ暗な
      セクションが無いか。洞窟と地表の両方で確認。
- [ ] **バイオームの色**：草・水の色が場所ごとに正しいか
      （404 のバイオームは列ごと 256 件の旧形式）。
- [ ] **エンティティのスポーン**：ボート・トロッコ・矢・アイテム・
      経験値オーブ・絵画・落下ブロックが正しい姿で出るか
      （オブジェクト表の振り分け確認）。動物・モンスターが
      Spawn Entity Living 経由で正しく出るか。
- [ ] 看板・本・コマンドブロック等の座標指定 UI が正しい場所を
      指すか（座標の詰め方が 1.14 と違う世代のため）。
- [ ] 村人との取引画面：404 には Trade List 自体が無いため、
      新しいサーバーで取引画面は開けない想定（制限として記録済み）。
      実機でも変な画面にならず安全に無視されるか。
- [ ] ベッドで寝たときの挙動（PLAY_BED は落とすため、寝る演出が
      無い／起床がおかしくないか）。
- [ ] 404 クライアントに 1.13.2 用パック（pack_format 4）が提示され、
      受け入れ後に文字化け・欠落テクスチャが無いか。
- [ ] 2人以上の実クライアントで相互に見えるか（フェイククライアントでは
      実バニラが Player Info／スポーンを送らないため未検証。全バージョン共通の最重要項目）。
- [ ] Bedrock クライアントから内部 404 サーバーへ参加できるか
      （単体テストのみで、実機・統合とも未実施）。

### C. 既知の制限（実機でも再現する想定）

- Declare Recipes／Statistics／Tags／World Event ID は全方向で未実装。
- Trade List は 404 に存在しないため、新しいサーバー相手でも
  取引画面は開けない。
- PLAY_BED は落とす（ベッドの寝る演出なし）。
- チャンクのスカイライトは近似で合成する場合がある（光データが無い
  セクション）。heightmap は空で合成される。
- バイオームの変種（hills 等）は新しいバージョン側では素のバイオームに
  寄るため、草・水の色が実機でも単調になる場合がある。
- その他は `docs/PROXY-1.13.2.md` の「残る制限」参照。
