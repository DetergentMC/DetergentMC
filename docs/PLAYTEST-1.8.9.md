# DetergentMC 1.8.9 実機プレイテスト — チェックリスト

2026-11-19 作成、Stage A〜D 完了に合わせて作成。1.8 系
クライアント（プロトコル47）で各サーバーに参加する実機確認の
ための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.8.9.md` を参照。

## 0. この手順書の読み方

DetergentMC の 47 対応は **Stage A〜E まで完了**。分割検証と
実バニラ統合テスト（ProxyIntegrationTest の統合セル71件
全合格）で確認済みだが、**本物のゲームクライアントでの
確認は未実施**。このチェックリストはその実機確認のための
ものである。

47 は 1.8〜1.8.9 の全10リリースが同一プロトコルで、107（1.9）
との世代差はこれまでで最大（チャンク形式・entityMetadata
形式・エンティティ座標形式が別物）。実機での重点は：
**チャンク表示（固定詰め変換と Map Chunk Bulk 分割）が正しい
こと**、**エンティティの位置（固定小数点変換）がずれない
こと**、**メタデータの bitfield 変換でエンティティの見た目が
崩れないこと**、**Teleport Confirm 合成経路（47 クライアント
× 新しいバックエンド）で移動が止まらないこと**、
**Keep Alive（応答 ID 0x00）の長時間セッションでの安定性**。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 47 のパケット ID 列（`PacketIds47Test`：プレイ状態で
  107 と共通 104 件・ID 差分 96 件、47 専用は
  map_chunk_bulk／set_compression／update_entity_nbt の
  3件だけであることを固定）。
- 対応クライアント一覧の最古が 47 で、107／108／109／110／
  210／315／316 が残り、計 41 プロトコル
  （`ClientAdapter47Test`。最古脱落の罠を固定）。
- レジストリ写像の共有名同一性と近似
  （`RegistryRemapper47Test`：end_rod のメタ写像、
  frosted_ice→ice、elytra→leather_chestplate、
  shulker→ブタ、音名 block.stone.break ⇔ dig.stone 等）。
- チャンクの往復変換と Map Chunk Bulk の分割
  （`ChunkTranslator47Test`：u16 bitMap、セクション
  12,288 バイト、bulk 分割後のデータ長）。
- メタデータの型変換と bitfield ワイヤ往復
  （`ChunkTranslator47Test`：先頭バイト (型<<5)|キー、
  終端 0x7F）。
- スポーンの固定小数点往復（10.5→336 等）、Position の
  teleportId 分離と Teleport Confirm 合成、効果 ID の境界
  （22→23 は可、23 は落とす）、音響効果の名前化と pitch
  u8 化（`ChunkTranslator47Test`）。

### B. 実機でしか確認できない項目

- [ ] 1.8.9 クライアントで 1.8.9 サーバー（内部）に参加し、
      チャンク表示・移動・チャットが正常か（Map Chunk Bulk
      分割と固定詰め変換の確認）。
- [ ] 1.8.9 クライアントで新しいサーバー（例：1.20.4）に
      参加できるか。テレポート（乗り物・コマンド・エンダー
      パール等）で移動が止まらないか（Teleport Confirm
      合成経路の確認。最重要）。
- [ ] 新しいクライアント（例：1.20.4）で 1.8.9 サーバーに
      参加し、地形・エンティティの位置がずれて見えないか
      （固定小数点変換の確認）。
- [ ] エンティティの見た目（防具・持ち物・ポーション効果・
      名前表示等）がメタデータ変換で崩れないか。
- [ ] 1.8.9 クライアントでネザーへ移動し、ディメンションが
      正しく切り替わるか（スカイライト無し次元でのチャンク
      表示を含む）。
- [ ] リソースパックの要求→応答の流れが 1.8.9 クライアント
      で完走するか（空 hash の受け付けは Stage E で実バニラ
      1.8.9 に対して確認済み。実機での表示確認が残る）。
- [ ] shulker のいる場所でブタとして表示されるか
      （1.8.9 クライアント→1.9 以上のサーバー）。chorus や
      purpur 系ブロックが end_stone として見えるか。
- [ ] Keep Alive（応答 ID 0x00）のため、30 分以上の接続で
      切断されないか。
- [ ] 2 人以上のプレイヤーが互いに見えるか（全バージョン
      共通の最優先確認項目。偽クライアントでは検証不能）。
