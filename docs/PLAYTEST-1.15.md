# DetergentMC 1.15 実機プレイテスト — チェックリスト

2026-11-17 作成。1.15 クライアント（プロトコル573）で各サーバーに参加する
実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.15.md` を参照。

## 0. この手順書の読み方

DetergentMC の 573 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.15
クライアントでの見た目・挙動を確かめること。

573 のワイヤ形式は 575（1.15.1）／578（1.15.2）と完全一致することが
実データで証明済みのため、実機でも 578 のプレイテスト
（`docs/PLAYTEST-1.15.2.md`）とほぼ同じ結果が予想される。差が出ると
したらプロトコル番号に依存する出し分け（リソースパックの選択など）
である。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 573クライアントの 1.15 サーバー（内部573）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake573ClientJoinsRealVanilla115ThroughProxy`）。
  Join Game が 573 形式（次元は数値 0）で届くこと、Spawn Position 0x4e、
  Keep Alive 0x21→0x0f を確認。
- 573クライアントの 1.15.1 サーバー（内部575）への参加・チャット・移動
  （`fake573ClientJoinsRealVanilla1151ThroughProxy`）。形式が同一のため
  変換なしで届く。
- 575クライアントの 1.15 サーバー（内部573）への参加・チャット・移動
  （`fake575ClientJoinsRealVanilla115ThroughProxy`）。
- 573 用リソースパック（pack_format 5、`detergentmc-pack-1.15.zip`）の
  生成と配信。外部モードの `resource-pack.url-573`／`sha1-573` も配線済み。

### B. 実機でしか分からない項目

- [ ] 本物の 1.15 クライアントで内部 573／575／578／758 サーバーへ参加し、
      地形・ブロックの見た目が崩れていないか。
- [ ] 573 クライアントに 1.15 用パック（pack_format 5）が提示され、
      受け入れ後に文字化け・欠落テクスチャが無いか。
- [ ] 2人以上の実クライアントで相互に見えるか（フェイククライアントでは
      実バニラが Player Info／スポーンを送らないため未検証。全バージョン共通の最重要項目）。
- [ ] Bedrock クライアントから内部 573 サーバーへ参加できるか
      （単体テストのみで、実機・統合とも未実施）。

### C. 既知の制限（実機でも再現する想定）

- Declare Recipes／Statistics／Tags／World Event ID は全方向で未実装。
- その他は 578 と同じ制限（`docs/PROXY-1.15.2.md` の「残る制限」参照）。
