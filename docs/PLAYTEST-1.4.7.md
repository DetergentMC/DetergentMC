## 0. この手順書の読み方

DetergentMC の 51 対応は **Stage E まで完了（2026-11-20）**。
単体テスト（分割検証 全 4,830 件・失敗 0）と Stage A の
実測採取（実バニラ 1.4.7 への暗号化ログイン＋歩行＋
チャット 112 パケット完全解析、チャンクバルク実物 34 件・
169 チャンクのサイズ検算まで一致）に加え、実バニラ
統合テスト（ブリッジ fake51→実バニラ 1.7.10、ダイレクト
fake51→実バニラ 1.4.7＝暗号化ログイン込み、51 の §1
ピング完全形、回帰を含む統合セル合計 102 件全合格）でも
確認済み。**残るは本物のゲームクライアントでの確認のみ**。
このチェックリストはその実機確認のためのものである。
1.4.6 は jar 抽出レベルで差分ゼロを確認したのみで、
採取・統合セルは 1.4.7 で代表させている。

51 で特に注意すべき点：

- **スコアボードと名前付きパーティクルが無い**（どちらも
  1.5 の追加）。ブリッジモードではスコアボード表示も
  パーティクル指定スポーンも 51 クライアントには届かない。
- **ウィンドウタイトルは常にリテラル**（useTitle フラグ
  自体が無い）。翻訳キー形式のタイトルはそのまま文字列と
  して表示される。
- **1.5 の追加ブロック・アイテムは近似**：ホッパー／
  ドロッパー→ディスペンサー、コンパレータ→リピーター、
  ネザークォーツ鉱石→ネザーラック、クォーツブロック→
  白羊毛、レッドストーンブロック→赤羊毛、日照センサー→
  石ハーフブロック、クォーツハーフ→砂岩ハーフ、
  トラップチェスト→チェスト、感圧板（軽量／重量）→
  木／石の感圧板、クォーツの階段→オークの階段、
  起動レール→パワードレール。アイテムはコンパレータ→
  リピーター、ネザーレンガ→レンガ、ネザークォーツ→
  ダイヤモンド、TNT／ホッパー付きトロッコ→通常トロッコ。
- **トロッコの変種**：TNT・スポナー・ホッパー付きは通常
  トロッコに見える（チェスト・かまど付きはそのまま）。
- 61／60 と共通の制限も継承する：**体力は整数（I16）**、
  **能力速度はバイト量子化**、**馬は豚**、**属性（0x2C）と
  乗り物操作（0x1B）が無い**、馬ウィンドウは無い。
- **1.4.7 と 1.4.6 の混在**：どちらのクライアントも同じ
  プロトコル 51 で参加できる。バックエンドも
  `minecraft-version` に `1.4.7` と `1.4.6` のどちらを
  書いてもダイレクトモードで受けられる（ピングには
  設定した名前がそのまま出る）。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 対応レガシー一覧＝[78, 74, 73, 61, 60, 51] の固定と、
  51 表が 61 表から欠落5件＋0x64 差し替えだけであることの
  固定（`LegacyPacketTableTest`）。
- 51 コーデックでの全パケット往復、open_window_notitle の
  ワイヤ長（61 より useTitle の 1 バイト短い）、51 に無い
  パケットの書き込みが例外になること
  （`LegacyPacketIOTest`）。
- 変換器の 51 処理：体力の整数化、速度変換、リードフラグ
  落ち、馬→豚、スコアボード／パーティクルの落とし、
  トロッコ変種 data の落とし、51 向けスロット／ブロック
  近似（`LegacyPlayTranslatorTest`、`LegacyChunkRemapTest`）。
- フェイク相手での E2E（`LegacyFrontendEndToEndTest`：
  1.4.7 バックエンドへのダイレクト中継（体力・速度・
  ウィンドウを開く形で中継）、ブリッジでの 0x85／0x2C
  落とし、§1 ピング 51 / 1.4.7 と 51 / 1.4.6）。
- アダプタ発見（1.4.7 と 1.4.6 の両方）と両名のダイレクト
  配線（`LegacyAdapterTest`、コア側 `LegacyWiringTest`）。

### B. 実機で重点的に見る項目

1. **レガシーピング**：1.4.7／1.4.6 クライアントの
   サーバー一覧に MOTD・人数が表示されること（完全形
   ピングで §1）。
2. **ログイン列（ブリッジ）**：暗号化を含むログインが
   最後まで進み、スポーンできること。61／78 クライアント
   と同時に混在参加できること。1.4.7 クライアントと
   1.4.6 クライアントの同時参加も確認する。
3. **ログイン列（ダイレクト）**：`minecraft-version: 1.4.7`
   と `1.4.6` の両方で起動し、内部バニラ（Java 8）へ直接
   つながること。61 クライアントが "Outdated client!" で
   蹴られること。
4. **近似ブロック**：現代側で置いたホッパー・クォーツ
   系・レッドストーンブロック・日照センサーが、51
   クライアントで上記の近似として見えること。
5. **トロッコの変種**：TNT付きトロッコが通常トロッコに
   見えること、チェスト付きがそのまま見えること。
6. **スコアボードの不在**：現代側でスコアボードを表示
   しても 51 クライアントに何も出ず、接続が切れないこと。
7. **体力表示**：ダメージを受けて体力バーが正しく減る
   こと（整数化の影響範囲の確認）。
8. **チャンク表示・移動・Keep Alive・エンティティ**：
   PLAYTEST-1.6.4.md の同項目と同じ観点。
