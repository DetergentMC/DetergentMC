# DetergentMC 1.14 実機プレイテスト — チェックリスト

2026-11-17 作成。1.14 クライアント（プロトコル477）で各サーバーに
参加する実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.14.md` を参照。

## 0. この手順書の読み方

DetergentMC の 477 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.14
クライアントでの見た目・挙動を確かめること。

477 のワイヤ形式は 480（1.14.1）と完全同一（Stage A でパケットID・
レジストリ・形式の差分0を実データで証明済み）で、変換は
480／485／490／498 の経路を共用している。そのため 480 のプレイテスト
項目がそのまま当てはまる。477 固有の新しい変換分岐は無いので、重点は
「最古の対応クライアントとして一連の流れが実機でも通るか」に置く。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 477クライアントの 1.14 サーバー（内部477）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake477ClientJoinsRealVanilla114ThroughProxy`）。
- 477クライアントの 1.14.1 サーバー（内部480）への参加・チャット・移動
  （`fake477ClientJoinsRealVanilla1141ThroughProxy`）。
- 480クライアントの 1.14 サーバー（内部477）への参加・チャット・移動
  （`fake480ClientJoinsRealVanilla114ThroughProxy`）。
- 477 用リソースパック（pack_format 4、`detergentmc-pack-1.14.zip`）の
  生成と配信。外部モードの `resource-pack.url-477`／`sha1-477` も配線済み。
  477 パックが無い構成では 480 パックで代替することも確認済み。
- 掘削 ack が 477 クライアントにも 480 クライアントにも届かず
  （両方に存在しない）、498 クライアントには 0x5c で届くことは
  単体テストで確認済み（`ProxySession477Test`）。
- Trade List の demand と canRestock が 758→477形式で落ち、477形式→758 で
  demand=0 と canRestock=isRegularVillager として補われることは
  単体テストで確認済み（`ChunkTranslator477Test`。変換自体は 485 用を共用）。

### B. 実機でしか分からない項目

- [ ] 本物の 1.14 クライアントで内部 477／480／758 サーバーへ参加し、
      地形・ブロックの見た目が崩れていないか。
- [ ] 村人との取引画面が正しく開き、取引できるか（Trade List の
      canRestock 無し形式の実機確認）。新しいサーバーで 1.14
      クライアントに取引画面が出たとき、補充可否の表示が
      おかしくないか（canRestock は isRegularVillager で代用する近似）。
- [ ] ブロックを掘ったときのヒビ・破壊の見た目が正しいか
      （掘削 ack が無い世代のため、違和感が無いか）。
- [ ] チャンクの明るさ（光は別パケット Update Light のため、
      暗転・明るさの段差が無いか）と、バイオームによる草・水の色が
      場所ごとに正しいか。
- [ ] 477 クライアントに 1.14 用パック（pack_format 4）が提示され、
      受け入れ後に文字化け・欠落テクスチャが無いか。
- [ ] 2人以上の実クライアントで相互に見えるか（フェイククライアントでは
      実バニラが Player Info／スポーンを送らないため未検証。全バージョン共通の最重要項目）。
- [ ] Bedrock クライアントから内部 477 サーバーへ参加できるか
      （単体テストのみで、実機・統合とも未実施）。

### C. 既知の制限（実機でも再現する想定）

- Declare Recipes／Statistics／Tags／World Event ID は全方向で未実装。
- Trade List の canRestock は近似（isRegularVillager で代用）。
- バイオームの変種（hills 等）は新しいバージョン側では素のバイオームに
  寄るため、草・水の色が実機でも単調になる場合がある。
- その他は 480 と同じ制限（`docs/PROXY-1.14.1.md` の「残る制限」参照）。
