# DetergentMC 1.12.2 実機プレイテスト — チェックリスト

2026-11-18 作成（下書き）。1.12.2 クライアント（プロトコル340）で
各サーバーに参加する実機確認のための手順と、結果の記録用。
詳細な仕組みは `docs/PROXY-1.12.2.md` を参照。

## 0. この手順書の読み方

DetergentMC の 340 対応は Stage E まで完了し、実バニラ統合テスト
（fake340→実バニラ 1.12.2／1.13、fake393→実バニラ 1.12.2 を含む
41 セル）と分割検証（3,846 件・失敗 0）で確認済み。ただし
**本物のゲームクライアントでの確認は未実施**で、このチェック
リストはその実機確認のためのものである。

340 は **Flattening 前の最後の世代**で、393 との差は大きい
（パケットID差分95件、ブロックは (数値ID&lt;&lt;4)|メタデータ、
アイテムは全面振り直し＋itemDamage）。実機では特にブロックの
意味対応（色物ブロック）、インベントリの Damage 付け替え、
チャンクの直接パレット（13ビット）が重点になる。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 340 のパケット ID 表（存在120件、393 との差分95件）と、
  Trade List 等が 340 に無いこと（`PacketIds340Test`）。
- ブロック意味対応表・アイテム対応表の全件照合
  （`tools/verify-340-tables.py`）。wool の meta 色分裂、
  oak_log の軸、魚・染料・バナー・ベッド・頭の Damage 規約は
  `RegistryRemapper340Test`／`ChunkTranslator340Test`／
  `ProxySession340Test`（758 サーバーの Set Slot の salmon が
  340 クライアントで fish＋itemDamage 1 になる等）で固定済み。
- チャンクの 340 変換（crossing 詰め、バイオーム u8）と
  座標再パック（`ChunkTranslator340Test`、
  `BedrockChunkTranslator340Test`）。
- 効果の ±1 付け替え、Scoreboard Objective の型文字列化、
  Teams の並び替え、絵画タイトル文字列、メタデータ型番号の
  付け替え（`ChunkTranslator340Test`）。
- 340 用リソースパック（pack_format 3、旧レイアウト、
  `detergentmc-pack-1.12.2.zip`）の生成と配信、340 パックが
  無い構成での 393 パック代替（`ResourcePack*340Test`）。
- 対応クライアント一覧の最古が 340 で、393／401／404 が
  脱落していないこと（`ClientAdapter340Test`）。

### B. 実機でしか分からない項目

- [ ] 本物の 1.12.2 クライアントで内部 340／393／404／758
      サーバーへ参加し、地形・ブロックの見た目が崩れて
      いないか。
- [ ] **色物ブロックの見た目**：羊毛・ステンドグラス・コンクリート
      等、meta が色を担うブロックが正しい色で表示されるか。
      新しいサーバー側で色付きベッド／バナーを置いたとき、
      340 クライアントで代表色（白）に見える近似が許容範囲か。
- [ ] **インベントリ／スロット**：340 の slot は itemDamage 形式。
      魚・染料等の Damage 規約アイテムの出し入れ、Window Click、
      Set Creative Slot が実機で正しく動くか。ダメージ値のある
      道具（耐久）が正しく表示されるか。
- [ ] **チャンクの直接パレット**：ブロック種が多いセクションで
      13ビット直接パレットになり、ブロックが化けていないか。
- [ ] **看板・本・コマンド系の欠落**：レシピ系と Statistics を
      落としている影響（レシピ本が開けない等）が想定どおりか。
      データパックが無いため /trigger ブリッジが使えないことの
      影響範囲の確認。
- [ ] **エンティティのスポーン**：ボート等のオブジェクト系
      （オブジェクト表）と生物系（モブ ID）の振り分けが実機で
      正しいか。特にスポーンエッグ（常に pig 近似）。
- [ ] **2人プレイでの相互表示**：フェイククライアントでは
      確認できない最重要項目。2つの本物クライアントで互いの
      姿・移動・設置ブロックが見えるか。
