# DetergentMC 1.14.3 実機プレイテスト — チェックリスト

2026-11-17 作成。1.14.3 クライアント（プロトコル490）で各サーバーに
参加する実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.14.3.md` を参照。

## 0. この手順書の読み方

DetergentMC の 490 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.14.3
クライアントでの見た目・挙動を確かめること。

490 のワイヤ形式は 498（1.14.4）とほぼ同一（差は掘削 ack の有無と
Trade List の demand だけ）で、変換は 498 の経路を共用している。
そのため 498 のプレイテスト項目の大半はそのまま当てはまるが、
村人取引（Trade List の demand が無い世代）と掘削まわりは
490 固有の分岐を通るので重点的に見てほしい。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 490クライアントの 1.14.3 サーバー（内部490）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake490ClientJoinsRealVanilla1143ThroughProxy`）。
- 490クライアントの 1.14.4 サーバー（内部498）への参加・チャット・移動
  （`fake490ClientJoinsRealVanilla1144ThroughProxy`）。
- 498クライアントの 1.14.3 サーバー（内部490）への参加・チャット・移動
  （`fake498ClientJoinsRealVanilla1143ThroughProxy`）。
- 490 用リソースパック（pack_format 4、`detergentmc-pack-1.14.3.zip`）の
  生成と配信。外部モードの `resource-pack.url-490`／`sha1-490` も配線済み。
- 掘削 ack が 490 クライアントには届かず（490 に存在しない）、
  498 クライアントには 0x5c で届くことは単体テストで確認済み
  （`ProxySession490Test`）。
- Trade List の demand が 758→490 で落ち、490→758 で 0 として
  補われることは単体テストで確認済み（`ChunkTranslator490Test`）。

### B. 実機でしか分からない項目

- [ ] 本物の 1.14.3 クライアントで内部 490／498／758 サーバーへ参加し、
      地形・ブロックの見た目が崩れていないか。
- [ ] 村人との取引画面が正しく開き、取引できるか（Trade List の
      demand 無し形式の実機確認）。逆に、新しいサーバーで 1.14.3
      クライアントに取引画面が出るか。
- [ ] ブロックを掘ったときのヒビ・破壊の見た目が正しいか
      （掘削 ack が無い世代のため、違和感が無いか）。
- [ ] チャンクの明るさ（光は別パケット Update Light のため、
      暗転・明るさの段差が無いか）と、バイオームによる草・水の色が
      場所ごとに正しいか。
- [ ] 490 クライアントに 1.14.3 用パック（pack_format 4）が提示され、
      受け入れ後に文字化け・欠落テクスチャが無いか。
- [ ] 2人以上の実クライアントで相互に見えるか（フェイククライアントでは
      実バニラが Player Info／スポーンを送らないため未検証。全バージョン共通の最重要項目）。
- [ ] Bedrock クライアントから内部 490 サーバーへ参加できるか
      （単体テストのみで、実機・統合とも未実施）。

### C. 既知の制限（実機でも再現する想定）

- Declare Recipes／Statistics／Tags／World Event ID は全方向で未実装。
- バイオームの変種（hills 等）は新しいバージョン側では素のバイオームに
  寄るため、草・水の色が実機でも単調になる場合がある。
- その他は 498 と同じ制限（`docs/PROXY-1.14.4.md` の「残る制限」参照）。
