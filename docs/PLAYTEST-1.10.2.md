# DetergentMC 1.10.2 実機プレイテスト — チェックリスト

2026-11-19 作成、Stage A〜D 完了に合わせて作成。1.10.2 クライアント
（プロトコル210）で各サーバーに参加する実機確認のための手順と、
結果の記録用。詳細な仕組みは `docs/PROXY-1.10.2.md` を参照。

## 0. この手順書の読み方

DetergentMC の 210 対応は **Stage E まで完了**。
単体テスト（分割検証 4,182 件・失敗 0）と**実バニラ統合テスト
（ProxyIntegrationTest の統合セル 56 件すべて成功）で確認済み**
だが、**本物のゲームクライアントでの確認は未実施**。
このチェックリストはその実機確認のためのものである。

210 は 1.10／1.10.1／1.10.2 の3リリース共通プロトコルで、315（1.11）
との差分はパケットID差分 0 件・形式差分 4 件。実機では特に、
**形式差分 4 件の見え方**（スポーン時の種別、タイトル／アクション
バーの表示、アイテム回収、ブロック設置位置のカーソル換算）、
**近似の見え方**（シュルカーボックス→チェスト、observer→
ドロッパー、亜種の畳み込み）、**Keep Alive（varint）の長時間
セッションでの安定性**が重点になる。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 210 のパケット ID 表が 315 と全件一致（`PacketIds210Test`：
  id210 == id315 を全 283 エントリで固定。210 に存在するのは
  113 件）。
- 対応クライアント一覧の最古が 210 で、315／316／335／338／340 が
  残り、計 36 プロトコル（`ClientAdapter210Test`。最古脱落の
  罠を固定）。
- 形式差分 4 件の境界変換（`ChunkTranslator210Test`）：スポーン
  living の種別 u8 幅、block_place カーソルの i8⇔f32 換算、
  collect の pickupItemCount 付け外し、title の action 番号
  （times=2、clear=3、reset=4）とアクションバーの
  チャット position=2 経由。
- レジストリ写像の代表値と往復（`RegistryRemapper210Test`）：
  observer→ドロッパー（メタ保持）、シュルカーボックス→チェスト、
  totem→金リンゴ、shulker_shell→プリズマリンシャード、
  亜種の畳み込み（husk→ゾンビ等）、1.11 新規モブ→ブタ。

### B. 実機でしか確認できない項目

1. **参加と移動**：1.10.2 クライアントで 210／315／335／758／765
   の各内部サーバーへ参加し、チャンクが欠けずに表示されるか。
   1.10／1.10.1 クライアントでも同じサーバーへ参加できるか
   （プロトコル共通の確認）。
2. **Keep Alive の安定性**：30 分以上接続し続け、切断されないか
   （この世代は KA 間隔が短い）。
3. **タイトルとアクションバー**：新バージョン側から送った
   タイトル／サブタイトル／表示時間が 210 クライアントで正しく
   出るか。アクションバー（新側）がチャット欄の上に表示されるか。
4. **ブロック設置のカーソル換算**：ブロックの端を狙って設置した
   とき、設置位置が大きくずれないか（i8 格子への丸めの影響）。
5. **近似の見え方**：シュルカーボックスがチェストに見えること、
   observer がドロッパーに見えること、husk／stray 等の亜種が
   基本種に見えること、evoker／vex／llama がブタに見えること。
6. **2 人同時参加時の相互表示**：プレイヤー同士が見えるか
   （fake クライアントでは原理的に確認できない最重要項目）。
7. **インベントリ操作**：スロット形式が旧形式（i16）の世代のため、
   アイテムの移動・分割・ドロップが正しく同期するか。

### C. 既知の制限（実機でも再現する想定）

- trigger ブリッジ（/trigger d_hello 等）はデータパックが無い
  世代のため 210 バックエンドでは使えない。
- シュルカーボックスの色は失われる。向きは一部のみ保持。
- Declare Recipes／Statistics／Tags／World Event ID は未実装
  （表示されない）。
