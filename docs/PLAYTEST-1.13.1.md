# DetergentMC 1.13.1 実機プレイテスト — チェックリスト

2026-11-18 作成。1.13.1 クライアント（プロトコル401）で各サーバーに
参加する実機確認のための手順と、結果の記録用。詳細な仕組みは
`docs/PROXY-1.13.1.md` を参照。

## 0. この手順書の読み方

DetergentMC の 401 対応は、プロトコルレベルではフェイククライアント＋
実バニラの統合テストと単体テストで検証済みだが、**本物のゲーム
クライアントでの確認は未実施**。実機テストの目的は、本物の 1.13.1
クライアントでの見た目・挙動を確かめること。

401 は 404（1.13.2）とパケットID・レジストリ・形式がすべて同一で、
違うのはスロットの符号化（旧形式：itemId が i16、空は -1）だけ。
そのため実機での重点は **インベントリまわり**（アイテムの表示・
持ち替え・クリック・クリエイティブでの取得）に移る。地形・チャンク・
スポーン等は 404 のプレイテスト項目がそのまま当てはまる。

### A. プロトコルレベルで検証済みの項目（実機では再現の確認）

- 401クライアントの 1.13.1 サーバー（内部401）への参加・スポーン・
  チャット・移動（`ProxyIntegrationTest.fake401ClientJoinsRealVanilla1131ThroughProxy`）。
- 401クライアントの 1.13.2 サーバー（内部404）への参加・チャット・移動
  （`fake401ClientJoinsRealVanilla1132ThroughProxy`）。
- 404クライアントの 1.13.1 サーバー（内部401）への参加・チャット・移動
  （`fake404ClientJoinsRealVanilla1131ThroughProxy`）。
- スロットの付け替え（Window Items／Set Slot／Entity Equipment／
  メタデータ内スロット／アイテム粒子／Advancements アイコン／
  Window Click／Set Creative Slot の往復）は単体テストで確認済み
  （`SlotTranslator401Test`、`ProxySession401Test`）。
- 401 用リソースパック（pack_format 4、`detergentmc-pack-1.13.1.zip`）の
  生成と配信。外部モードの `resource-pack.url-401`／`sha1-401` も配線済み。
  401 パックが無い構成では 404 パックで代替することも確認済み。

### B. 実機でしか分からない項目

- [ ] 本物の 1.13.1 クライアントで内部 401／404／477／758 サーバーへ
      参加し、地形・ブロックの見た目が崩れていないか。
- [ ] **インベントリの表示**：参加直後のホットバー・インベントリの
      アイテムが正しい種類・個数で表示されるか（Window Items の
      旧形式スロット変換が本番）。
- [ ] **アイテムの持ち替え・移動**：クリックでのアイテム移動、
      ドラッグ、数字キーでの入れ替えが正しく動くか
      （Window Click の旧形式→現行形式変換）。
- [ ] **クリエイティブのアイテム取得**：クリエイティブインベントリ
      からアイテムを取れるか（Set Creative Slot の変換）。
- [ ] **装備の見え方**：他のプレイヤー／モブの手持ち・防具が正しく
      表示されるか（Entity Equipment、メタデータ内スロット）。
      ※ 二人プレイの見え方はフェイククライアントでは確認できない
      最優先項目（全バージョン共通）。
- [ ] **アイテム粒子**：ブロックを壊したときの粒子が正しい
      アイテムで表示されるか（World Particles のアイテム粒子）。
- [ ] **進捗画面**：Advancements のアイコンが正しく表示されるか。
- [ ] エンチャント等で **NBT 付きアイテム**（ダメージ値のある道具・
      名前付きアイテム）が正しく表示・保持されるか
      （NBT はバイト列のまま写す実装のため、ここが確認点）。
- [ ] 404 のプレイテスト項目（自然地形のブロック精度、チャンクの
      明るさ、バイオームの色、スポーンの振り分け）もあわせて確認。
