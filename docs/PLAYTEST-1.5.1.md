# DetergentMC 1.5.1／1.5 実機プレイテスト — チェックリスト

2026-11-20 作成、60 の Stage A〜D 完了に合わせて作成。

## 0. この手順書の読み方

DetergentMC の 60 対応は **Stage E まで完了**。単体テスト
（分割検証）と Stage A の実測採取（実バニラ 1.5.1 への
暗号化ログイン＋歩行＋チャット 3,534 パケット完全解析、
実バニラ 1.5 でも 823 パケット完全解析）に加え、**実バニラ
統合テスト（Stage E の統合セル：ブリッジ fake60→実バニラ
1.7.10、ダイレクト fake60→実バニラ 1.5.1、ダイレクト
fake60→実バニラ 1.5、§1 ピング）で参加→チャット→
Keep Alive 応答→2通目のチャット到達まで確認済み**だが、
**本物のゲームクライアントでの確認は未実施**。この
チェックリストはその実機確認のためのものである。

60 は 61（1.5.2）とワイヤ完全同一（実測確定）のため、注意点は
61 と同じである：

- **属性（0x2C）と乗り物操作（0x1B）が無い**（どちらも
  1.6 の追加）。ブリッジモードでは属性パケットは届かない。
- **体力は整数（I16）**。小数の体力は四捨五入されて表示
  される。
- **能力速度はバイト量子化**（飛行・歩行速度が 1/255 刻み、
  上限約 0.498）。速すぎる飛行速度は頭打ちになる。
- **1.6 の追加ブロック・アイテム・エンティティは近似**：
  カーペット／色付き粘土→同色の羊毛、堅焼き粘土→粘土、
  石炭ブロック→黒羊毛、干草→黄羊毛、馬→豚、馬鎧→
  チェストプレート、リード→糸、名札→紙。
- **馬ウィンドウはエンティティID無し**で開く。
- **1.5 と 1.5.1 の混在**：どちらのクライアントも同じ
  プロトコル 60 で参加できる。バックエンドも
  `minecraft-version` に `1.5.1` と `1.5` のどちらを書いても
  ダイレクトモードで受けられる（ピングには設定した名前が
  そのまま出る）。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 対応レガシー一覧＝[78, 74, 73, 61, 60] の固定と、60 表が
  61 表と項目ごとに一致することの固定
  （`LegacyPacketTableTest`）。
- 60 コーデックでの全パケット往復と、ワイヤが 61 の符号化と
  バイト単位で一致すること（`LegacyPacketIOTest`）。
- 変換器の 60 処理が 61 と同じ 1.5 世代変換になること
  （体力の整数化、速度変換）（`LegacyPlayTranslatorTest`）。
- フェイク相手での E2E（`LegacyFrontendEndToEndTest`：
  1.5.1 バックエンドへのダイレクト中継（体力を 61 と同じ
  形式で中継）、ブリッジでの 0x85／0x2C 落としと補助値
  合成、§1 ピング 60 / 1.5.1 と 60 / 1.5）。
- アダプタ発見（1.5.1 と 1.5 の両方）と両名のダイレクト
  配線（`LegacyAdapterTest`、コア側 `LegacyWiringTest`）。

### B. 実機で重点的に見る項目

1. **レガシーピング**：1.5.1／1.5 クライアントのサーバー
   一覧に MOTD・人数が表示されること（完全形ピングで §1）。
2. **ログイン列（ブリッジ）**：暗号化を含むログインが最後
   まで進み、スポーンできること。61／78／74／73 クライアント
   と同時に混在参加できること。1.5 クライアントと 1.5.1
   クライアントの同時参加も確認する。
3. **ログイン列（ダイレクト）**：`minecraft-version: 1.5.1`
   と `1.5` の両方で起動し、内部バニラ（Java 8）へ直接
   つながること。61 クライアントが "Outdated client!" で
   蹴られること。
4. **体力表示**：ダメージを受けて体力バーが正しく減る
   こと（整数化の影響範囲の確認）。
5. **近似ブロック**：現代側で置いたカーペット・石炭
   ブロック・干草・色付き粘土が、60 クライアントで羊毛／
   粘土として見えること（色の維持を含む）。
6. **馬の見え方**：現代側の馬が 60 クライアントで豚に
   見えること（スポーン種別の近似）。
7. **チャンク表示・移動・Keep Alive・エンティティ**：
   PLAYTEST-1.6.4.md の同項目と同じ観点。
