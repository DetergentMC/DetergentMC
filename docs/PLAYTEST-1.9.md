# DetergentMC 1.9 実機プレイテスト — チェックリスト

2026-11-19 作成、Stage A〜D 完了に合わせて作成。1.9 クライアント

## 0. この手順書の読み方

DetergentMC の 107 対応は **Stage E まで完了**。単体テスト
（分割検証 4,522 件・失敗 0）と Stage A の実測に加えて、
**実バニラ統合テスト（ProxyIntegrationTest の統合セル
新規 3＋回帰 65＝68 セル全合格）でも確認済み**だが、
**本物のゲームクライアントでの確認は未実施**。この
チェックリストはその実機確認のためのものである。

107 は 1.9 単独プロトコルで、108（1.9.1）との差分は Join Game
の dimension が i8 であることの1件だけ（実バニラ 1.9 の
ワイヤ採取と protocol.json 全面比較で確定済み）。実機での
重点は 108 から引き継ぐ項目に加えて：**ネザーへの移動で
dimension の i8⇔i32 付け替えが正しいこと**（符号拡張の
化けが無いか）、**107 バックエンドのチャンクのゼロ埋め癖が
地形表示に影響しないこと**、**チャンクのブロックエンティティ
欠落の見え方**、**看板のライブ更新が届かないこと**、
**近似の見え方**と **Keep Alive（varint）の長時間セッション
での安定性**。

### A. 単体テストで検証済みの項目（実機では再現の確認）

- 107 のパケット ID 列が 108 と全エントリ完全一致すること
  （`PacketIds107Test`：全 284 エントリで id107 == id108 を
  固定。107 に存在するのは 114 件）。
- 対応クライアント一覧の最古が 107 で、108／109／110／210／
  315／316 が残り、計 40 プロトコル（`ClientAdapter107Test`。
  最古脱落の罠を固定）。
- レジストリ写像が全入力域で 108 と一致すること
  （`RegistryRemapper107Test`。委譲の正しさを固定）。
- Join Game の dimension が i8 で読み書きされ、ネザー
  （−1）が 758 との往復で化けないこと
  （`PlayTranslator107Test`）。
- ゼロ埋めを含む 107 チャンクの変換結果が、ゼロ埋め無しと
  同一になること（`ChunkTranslator107Test`。107 固有の癖）。
- チャンクの blockEntities 欠落の境界処理
  （`ChunkTranslator107Test`：107 形式に末尾が無いこと、
  758 側のブロックエンティティが 107 向けで落ちること、
  107→758 で空の列が補われること）。
- クライアント行き update_sign が正準経路で落ちること、
  sound_effect が 107 では 0x47 で届き pitch が u8 化される
  こと（`ProxySession107Test`）。

### B. 実機でしか確認できない項目

- [ ] 1.9 クライアントで 1.9 サーバー（内部）に参加し、
      チャンク表示・移動・チャットが正常か（107 バックエンド
      のチャンクのゼロ埋めが地形に影響しないことの確認）。
- [ ] 1.9 クライアントでネザーへ移動し、ディメンションが
      正しく切り替わるか（i8 dimension の付け替え確認）。
      新しいクライアントで 1.9 サーバーへ参加した場合も同様。
- [ ] 1.9 クライアントで新しいサーバー（例：1.20.4）に
      参加できるか。音のピッチが極端にずれて聞こえないか。
- [ ] 新しいクライアント（例：1.20.4）で 1.9 サーバーに
      参加し、看板の文字・チェストの中身がどう見えるか
      （107 のチャンクにはブロックエンティティが載らない
      ため、欠落が前提。エラーや切断にならないことの確認）。
- [ ] 1.9 サーバー側で看板を書き換えたとき、新しい
      クライアントにライブ更新が届かないこと（仕様どおりの
      制限であることの確認。切断やエラーにはならないこと）。
- [ ] リソースパックの要求→応答の流れが 1.9 クライアントで
      完走するか（空 hash の受け付け自体は Stage E の統合
      テストで実バニラ 1.9 が受け付けることを確認済み。
      実機での流れ全体の確認が残る）。
- [ ] polar_bear のいる場所でブタとして表示されるか
      （1.9 クライアント→新しいサーバー）。
- [ ] Keep Alive（varint）世代のため、30 分以上の接続で
      切断されないか。
- [ ] 2 人以上のプレイヤーが互いに見えるか（全バージョン
      共通の最優先確認項目。偽クライアントでは検証不能）。
